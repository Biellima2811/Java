# ☕ Curso Java Completo - Prof. Nelio Alves (Udemy)

Bem-vindo ao meu repositório de estudos! Este espaço é dedicado exclusivamente para armazenar os exercícios, desafios e projetos desenvolvidos durante o curso **"Java COMPLETO Programação Orientada a Objetos + Projetos"**, ministrado pelo professor Nelio Alves na plataforma Udemy.

## 🎯 Objetivo

O objetivo deste repositório é documentar minha evolução na linguagem Java, partindo da lógica de programação básica, aprofundando intensamente em Programação Orientada a Objetos (POO) e avançando até o desenvolvimento de aplicações completas utilizando os frameworks mais requisitados do mercado.

---

## 🚀 Tecnologias e Tópicos Abordados

Durante a jornada deste curso, diversas ferramentas e conceitos vitais para um desenvolvedor backend são explorados na prática:

*   **Lógica de Programação:** Estruturas sequenciais, condicionais e repetitivas.
*   **Java Core:** Sintaxe, tipos básicos, strings, arrays, listas e matrizes.
*   **Programação Orientada a Objetos (POO):** Classes, atributos, métodos, construtores, encapsulamento, herança e polimorfismo.
*   **Tratamento de Exceções:** Blocos try-catch e criação de exceções personalizadas para regras de negócio.
*   **Manipulação de Arquivos:** Leitura e escrita (I/O) utilizando as bibliotecas modernas do Java.
*   **Interfaces e Generics:** Criação de contratos, injeção de dependência e parametrização de tipos.
*   **Programação Funcional:** Expressões Lambda, funções de alta ordem, Predicates e a API de Streams.
*   **Banco de Dados Relacional:** Fundamentos de SQL, integração nativa via JDBC e padrão DAO.
*   **Mapeamento Objeto-Relacional (ORM):** Gerenciamento avançado de banco de dados com JPA e Hibernate.
*   **Desenvolvimento Web/Backend:** Construção de web services e APIs RESTful modernas utilizando Spring Boot.
*   **Interface Gráfica (Desktop):** Desenvolvimento de aplicações com telas visuais utilizando JavaFX e o padrão MVC.

## 📁 Estrutura do Repositório

Para facilitar a consulta, os projetos e exercícios estão organizados (ou sendo organizados) de acordo com os grandes módulos e conceitos abordados no curso:

*   `Logica_de_Programacao/`: Exercícios de nivelamento e algoritmos fundamentais.
*   `POO_Fundamentos/`: Primeiros projetos orientados a objetos (como simulações bancárias, controle de estoque, etc).
*   `Arquivos_e_Excecoes/`: Aplicações focadas em segurança de código e persistência em arquivos de texto.
*   `JDBC_e_Banco_de_Dados/`: Códigos de conexão direta com bancos de dados relacionais.
*   `JPA_Hibernate/`: Projetos focados em mapeamento ORM sem a necessidade de escrever queries em SQL puro.
*   `Spring_Boot_API/`: Projeto prático de um Web Service completo construído em Spring.
*   `Interface_JavaFX/`: Projetos desktop que abandonam o console e trazem janelas interativas.

*(Obs: Esta estrutura está em constante atualização conforme o meu progresso no curso).*

## 🛠️ Como Executar os Projetos

Para testar os códigos presentes neste repositório localmente, você precisará de:

*   Java JDK (versão 11 ou superior, recomendo a versão 17 ou 21).
*   Uma IDE moderna devidamente configurada (como IntelliJ IDEA, Eclipse ou Apache NetBeans).
*   MySQL e MySQL Workbench instalados (especificamente para os módulos avançados de Banco de Dados, JPA e Spring).

**Passo a passo:**
1. Clone este repositório: `git clone https://github.com/Biellima2811/Java.git`
2. Abra a pasta do módulo/projeto desejado na sua IDE.
3. Localize o arquivo `Program.java` ou `Main.java` (onde contém o método `public static void main`).
4. Execute o arquivo (Run).
